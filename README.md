### Автотесты для проверки программы, которая помогает заказать бургер в Stellar Burgers

### Реализованные сценарии

Создание пользователя:
- создан уникального пользователя;
- создан пользователя, который уже зарегистрирован;
- создан пользователя и не заполнить одно из обязательных полей.

Логин пользователя:
- вход под существующим пользователем;
- вход с неверным логином и паролем.
Создание заказа:
- с авторизацией;
- без авторизации;
- с ингредиентами;
- без ингредиентов;
- с неверным хешем ингредиентов.

### Структура проекта

- `allure_results` - пакет, содержащий allure-отчеты
- `tests` - пакет, содержащий тесты, разделенные по классам.
- `conftest.py` - для фикстур
- `data.py` - для Url, JSON-ответов

### Запуск автотестов

> `$ pytest`

**Установка зависимостей**

> `$ pip install -r requirements.txt`
